# Notice

## What this repository is

A collection of sixteen independent design-system reconstructions, produced for reference, study and
prototyping. Each kit documents a visual language — tokens, component specs, isolated previews, static UI
kits — as observed and rebuilt from scratch in plain HTML and CSS.

## What this repository is not

It is not affiliated with, endorsed by, sponsored by, or approved by any of the companies whose names
appear in it. No kit is an official release, an official design resource, or a redistribution of one. No
kit was built from a company's internal or licensed design files.

Folder names describe the visual language a kit reconstructs. They are not claims of authorship,
ownership, or partnership. Where a kit carries an internal product name — `Apple/` reconstructs a
fictional product called Pinguo, for example — that name is invented for the reconstruction and refers to
no real company.
